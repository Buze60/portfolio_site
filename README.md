# Bizuayehu Simachew - Portfolio Website

A modern, responsive portfolio website showcasing my skills as a Python Developer and Flutter Mobile App Developer.

## 🌟 Features

- **Modern Design**: Premium UI with smooth gradients, animations, and glassmorphism effects
- **Dark Mode**: Toggle between light and dark themes with persistent storage
- **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Interactive Animations**: 
  - Typing animation in hero section
  - Smooth scroll animations
  - Hover effects and micro-interactions
  - Animated skill progress bars
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Performance**: Optimized loading and smooth 60fps animations

## 🚀 How to View

Simply open `index.html` in your web browser:

1. Navigate to the portfolio folder
2. Double-click `index.html` 
3. Or right-click → Open with → Your preferred browser

**Recommended browsers**: Chrome, Firefox, Edge, Safari

## 📝 Customization

To customize the portfolio:

1. **Colors**: Edit CSS variables in `styles.css` (lines 8-30)
2. **Content**: Update text in `index.html`
3. **Typing Animation**: Modify the `texts` array in `script.js` (line 60)
4. **Skills**: Add/remove skills in the Skills section of `index.html`
